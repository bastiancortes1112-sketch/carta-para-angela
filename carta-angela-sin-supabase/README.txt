PROYECTO: CARTA PARA ANGELA ❤️

1. Abre esta carpeta en Visual Studio Code.
2. Abre index.html con Live Server para probarla.
3. En script.js cambia:
   - LOVE_PASSWORD
   - START_DATE
4. Para fotos:
   - Mete tus imágenes en la carpeta "fotos".
   - Nómbralas foto1.jpg, foto2.jpg, foto3.jpg y foto4.jpg.
5. Para música:
   - Mete un archivo llamado "music.mp3" en la carpeta principal.
6. Cuando esté lista, puedes publicarla gratis con GitHub Pages.

IMPORTANTE:
Esta versión NO usa Supabase ni base de datos. Por eso es mucho más fácil.
Las fotos y la música quedan incluidas dentro del proyecto.
Los mensajes compartidos entre celulares no están incluidos en esta versión.
La contraseña es solo una pantalla de acceso visual; no es seguridad real porque el código JavaScript queda público al publicar la página.
